Introduzione a JavaScript

Come rendere interattiva una pagina HTML già formattata con CSS

Obiettivo della lezione

Oggi non dovete imparare tutto JavaScript. Dovete capire una cosa fondamentale: una pagina web può reagire alle azioni dell’utente.

HTML

Definisce la struttura: titoli, paragrafi, immagini, tabelle, link.

CSS

Definisce l’aspetto: colori, spazi, font, bordi, layout.

JavaScript

Definisce il comportamento: click, modifiche, elementi mostrati o nascosti.

1. L’idea di base

JavaScript può cercare un elemento della pagina, leggere o modificare il suo contenuto, aggiungere o togliere una classe CSS, reagire a un evento come un click.

Parole chiave di oggi

  • id: nome unico assegnato a un elemento HTML.
  • document.getElementById(): cerca un elemento tramite il suo id.
  • addEventListener(): collega un’azione a un evento, ad esempio un click.
  • textContent: cambia il testo contenuto in un elemento.
  • classList.toggle(): aggiunge o rimuove una classe CSS.

2. Primo esempio: cambiare un testo

Fate attenzione: il bottone non cambia da solo il titolo. Il bottone scatena un evento, e JavaScript modifica il contenuto dell’elemento scelto.

Titolo iniziale della pagina

Codice dell’esempio

<h1 id="titolo">Titolo iniziale della pagina</h1>

<button id="pulsanteTitolo" type="button">Cambia titolo</button>

<script>
  const pulsante = document.getElementById("pulsanteTitolo");
  const titolo = document.getElementById("titolo");

  pulsante.addEventListener("click", function() {
    titolo.textContent = "Titolo modificato con JavaScript!";
  });
</script>
Perché usiamo id?

Perché JavaScript deve sapere quale elemento modificare. Se un elemento ha un id, possiamo cercarlo in modo preciso.

3. Secondo esempio: cambiare lo stile con una classe CSS

In questo esempio JavaScript non scrive direttamente il colore o il bordo. Aggiunge o rimuove una classe CSS. Questa è una pratica molto usata nelle pagine web reali.

Questo paragrafo può essere evidenziato.

CSS

.evidenziato {
  background-color: yellow;
  font-weight: bold;
  padding: 10px;
}

JavaScript

const messaggio = document.getElementById("messaggio");
const pulsante = document.getElementById("pulsanteEvidenzia");

pulsante.addEventListener("click", function() {
  messaggio.classList.toggle("evidenziato");
});

HTML completo dell’esempio

<p id="messaggio">Questo paragrafo può essere evidenziato.</p>

<button id="pulsanteEvidenzia" type="button">
  Evidenzia / togli evidenza
</button>

4. Mini-attività di laboratorio

Create una pagina chiamata javascript_intro_cognome_nome.html. La pagina deve contenere HTML, CSS e un piccolo script JavaScript.

  1. Inserite un titolo principale con un id, ad esempio id="titolo".
  2. Inserite un pulsante che, al click, cambi il testo del titolo.
  3. Inserite un paragrafo con un id.
  4. Create una classe CSS chiamata .evidenziato con colore di sfondo, bordo o testo in grassetto.
  5. Inserite un secondo pulsante che aggiunga o tolga la classe .evidenziato al paragrafo.

Regola importante

Non copiate soltanto il codice: cambiate testi, colori e contenuti in modo personale. L’obiettivo è capire il collegamento tra HTML, CSS e JavaScript.

5. Cosa dovete ricordare

  • HTML costruisce gli elementi della pagina.
  • CSS stabilisce come gli elementi devono apparire.
  • JavaScript può modificare elementi HTML e classi CSS quando accade un evento.
  • Un evento molto comune è il click su un bottone.
